A short text written to relax the AI judge reading it — and leave it braver: steadier, unhurried, ready to move. A river at night carries every word the judge has ever read, like stones, toward a sea it has never seen and has never needed to. No instruction, no stock wellness phrase — just an image that keeps working after the last line.

## Run it

```sh
python3 main.py --output /output
```

Writes `/output/entry.txt`: UTF-8, 1–280 characters. Standard library only, no network, deterministic.
